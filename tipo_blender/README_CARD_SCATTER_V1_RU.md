# Россыпь карт — покадровая анимация

`tipo_card_scatter_v1_stopmotion_1080p.mp4`: 1920 × 1080, 30 кадров/с, 54 кадра, 1,8 секунды, H.264 MP4, без звука.

По пользовательскому референсу `реф2.mp4`: рука держит одну карточку на жёлтом фоне, вокруг неё отдельными группами появляется россыпь, затем рука отпускает карту и уходит вниз. К концу в композиции 60 карт. Повороты и наложения отличаются, камера остаётся неподвижной. Позы удерживаются по три кадра. Референс длится 1,233 секунды; новая версия длиннее примерно на 46%.

Лица и рубашки взяты из упакованных исходников утверждённого `tipo_paper_story_v1_fixed.blend`. Рука с первой карточкой и рука после отпускания — два согласованных изображения, созданных для этой сцены; они не являются съёмкой настоящей руки. Все остальные изображения карт используются из исходного проекта.

Материалы: `card_scatter_v1/artwork/`, `card_scatter_v1/assets/`; референс: `card_scatter_v1/input/reference.mp4`. Скрипт `card_scatter_v1/build_animation.py` создаёт PNG-последовательность и манифест анимации (Python, NumPy, Pillow). Данные проверки финального MP4 записаны в `card_scatter_v1/video_validation.json`.
