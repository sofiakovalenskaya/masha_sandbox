# Сминание с углов — версия 7

`tipo_word_sequence_v7_corner_folds_1080p.mp4`: 1920 × 1080, 30 кадров/с, 191 кадр, 6,367 секунды, H.264 MP4, без звука.

Убрано проявление бумажной картинки через затухание. Начало построено на 12 отдельных геометрических позах: четыре угла непрозрачного листа поворачиваются вокруг диагональных линий сгиба. Рисунок закреплён на листе через UV-развёртку; при перевороте угла открывается светлая бумажная оборотная сторона. Прозрачность материала постоянно равна единице.

В течение всей начальной фазы складывания углов прямые участки верхнего и нижнего края остаются за границами кадра. Розовый фон сначала открывается только в угловых треугольных областях. Общего уменьшения листа в этой фазе нет. После первых угловых сгибов на непрозрачной поверхности последовательно появляются слабые, лёгкие и более выраженные фотографические заломы. Для них используются бумажные изображения версии 6; прозрачность материала не анимируется. Затем добавляются две непрозрачные позы сминания основной части, после которых продолжается бумажный финал версии 5 с комком и укатыванием вниз.

Первые 92 кадра анимации слов и 57 кадров прежнего бумажного финала сохранены без изменения пикселей. Добавлены 42 кадра физического складывания и сбора листа, по три кадра на позу. Последние 15 кадров — пустой розовый фон `#FF006F`.

`word_sequence_v7/build_corners.py` создаёт геометрические позы в Blender 4.3.2 (EEVEE). Материалы автоматически подготавливаются скриптом `prepare_materials.py`: цвет бумажной фактуры продолжается до краёв непрозрачной поверхности. `assemble_animation.py` собирает позы с прежней последовательностью; для промежуточного смятого листа используется изображение `word_sequence_v6/assets/paper_medium_creases.png`, без затухания. Нужны Python, Pillow, NumPy и SciPy; для экспорта — FFmpeg.

```bash
blender -b -t 4 -P word_sequence_v7/build_corners.py
python word_sequence_v7/assemble_animation.py
ffmpeg -framerate 30 -i word_sequence_v7/frames/frame_%04d.png -an -vf 'scale=in_range=full:out_range=tv:out_color_matrix=bt709,format=yuv420p' -c:v libx264 -preset slow -crf 16 -color_range tv -colorspace bt709 -color_trc bt709 -color_primaries bt709 -movflags +faststart tipo_word_sequence_v7_corner_folds_1080p.mp4
```

Параметры углов — в `corner_poses.json`, карта кадров — в `animation_manifest.json`. `video_validation.json` содержит проверки сохранённых кадров, отсутствия розовых полос на прямых участках краёв в начале, непрозрачности листа и готового MP4.
