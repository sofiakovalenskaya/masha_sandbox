# ТИПО — коробка и бумажный пролёт, версия 1

25 секунд, 1920 × 1080, 30 кадров/с, без звука. Одна перспективная камера и фирменный розовый фон и стол `#FF006F`.

## Файлы

- `tipo_paper_story_v1.mp4` — готовый ролик.
- `tipo_paper_story_v1.blend` — редактируемая сцена для Blender 4.3.2 и новее. Все текстуры встроены.
- `tipo_paper_story_v1.png` — финальная раскладка.
- `paper_story_v1/` — код построения, траектории, сетка бумаги, дополнительные оригинальные PNG и проверки.

Откройте `.blend`, сцена `TIPO_Paper_Story_v1`. Пробел — воспроизведение, F12 — рендер кадра, Ctrl+F12 — рендер ролика. Файл открыт на кадре 31; диапазон анимации — 1–750. На слабом компьютере воспроизведение во вьюпорте может идти медленнее готового MP4.

## Сценарий

| Время | Действие |
| --- | --- |
| 0–2,2 с | Появление и лёгкое зависание коробки №2 лицом к камере. |
| 2,2–4,1 с | Переворот крышкой вниз. |
| 4,15–5,6 с | Открывание крышки и синего клапана. |
| 5,55–10,3 с | 61 карта высыпается; камера спускается, карты приближаются к ней и удаляются. |
| 10,1–12,8 с | 14 игровых карт занимают места на столе. Остальные 47 уходят за пределы финальной композиции. |
| 11,5–19,8 с | Быстрый близкий пролёт по горизонтальной и вертикальной линиям. |
| 19,8–24 с | Отъезд и переход к общему виду сверху. |
| 24–25 с | Неподвижный общий план всей раскладки. |

## Сохранение дизайна

Коробка взята из утверждённого `tipo_box_61_cards_v4.blend`. Её сетки, материалы, UV и изображения не изменены: для открывания движутся копии крышки и клапана. Утверждённые исходники обеих коробок не перезаписаны; их SHA-256 проверяются по `ANIMATION_ASSETS.json`.

61 карта: 15 жёлтых, 15 зелёных, 15 синих, 15 розовых и одна чёрная карта правил. Рубашки и лица используют исходные PNG. Геометрия анимационных карт имеет толщину 0,25 мм, скруглённые углы и три независимых деформации: изгиб по X, изгиб по Y и скручивание. Движение поставлено ключевыми кадрами и не требует вычисления физической симуляции при открытии файла.

Финальная раскладка содержит 8 карт по горизонтали и 7 по вертикали, с одной общей картой H6/V5: всего 14 уникальных карт. Шаг центров 71,770833 мм, размер карты 65 мм. В горизонтальном ряду H3–H7 идут пять Airy. Порядок и место пересечения повторяют референс. H3 использует последний присланный оригинал «ТИПО! 06 — Д.png» с волнистым подчёркиванием; изображения не перерисованы. Для H4 и H7 взяты оригиналы 23 и 28 из «3 карты.zip».

Нет выделения выигрышной пятёрки, дополнительных надписей и звука. Анимация заканчивается общим планом; это сюжетный ролик, отдельный от ранее созданного зацикленного вращения коробки.

## Воспроизведение построения

Из корня репозитория:

```sh
blender --background --python-exit-code 1 --python tipo_blender/paper_story_v1/build_scene.py
blender --background tipo_blender/tipo_paper_story_v1.blend --python-exit-code 1 --python tipo_blender/paper_story_v1/validate_scene.py
```

Скрипт проверяет контрольную сумму исходной коробки, открывает её и создаёт отдельную сцену анимации. Для построения не нужны дополнительные Python-пакеты сверх поставляемых с Blender. `TIPO_STORY_SAMPLES` задаёт количество сэмплов Eevee при повторном построении; по умолчанию 4. В сохранённом проекте установлено 16 для повторного рендера. Видео рассчитано в исходном разрешении 1920×1080.
