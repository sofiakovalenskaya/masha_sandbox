К версии v10 добавлено продолжение после крупного плана правил.

Карта переворачивается вокруг вертикальной оси на оригинальную чёрную рубашку
с логотипом ТИПО!. Через 0,4 секунды цвет рубашки быстро переключается:
зелёный → розовый → жёлтый → синий, затем этот круг повторяется ещё раз.
Каждый цвет держится 0,2 секунды. Финал — синяя рубашка с логотипом.

Первые 228 кадров v10 полностью сохранены. Все рубашки — оригинальные PNG.
Карта остаётся квадратной, 972×972 пикселя в анфас, по центру кадра.
Фон и камера при смене цветов неподвижны. Переворот использует перспективную
проекцию с отображением тонкого ребра; логотип на обороте не зеркалится.

MP4: 1920×1080, 30 кадров/с, без звука.
Сборка: `python tipo_blender/card_scatter_v11/build_flip_colors.py`.
