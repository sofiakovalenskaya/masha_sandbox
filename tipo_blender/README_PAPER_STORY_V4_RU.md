# ТИПО — анимация v4

25 секунд, 1920×1080, 30 кадров/с, без звука.

Выпадение восстановлено на основе свободных траекторий первой версии: близкие пролёты, повороты и изгибы бумажных карт. Выпадают 30 карт, 31 остаётся внутри коробки. Камера приходит к столу до приземления первых двух карт и показывает их касание крупно. Затем проходит только по горизонтальному ряду и быстро отъезжает к общей раскладке из 14 карт. Фон и стол — фирменный жёлтый #FFD000. Появление коробки снизу с небольшим отскоком, затем неподвижная пауза.

Коробка №2, оригинальные изображения карт и порядок итоговой раскладки сохранены. Утверждённые исходные модели не перезаписываются. Все текстуры включены в файл Blender.

Открыть `tipo_paper_story_v4.blend`, нажать пробел для просмотра анимации; NumPad 0 включает вид камеры. Для видео использовать готовый MP4.

Воспроизведение сборки: Blender 4.3.2, `blender -b --python paper_story_v4/build_scene.py`. Скрипт берёт утверждённую модель `tipo_box_61_cards_v4.blend` из родительского каталога и проверяет её SHA-256. Готовый `.blend` не требует запуска скриптов или внешних изображений.
