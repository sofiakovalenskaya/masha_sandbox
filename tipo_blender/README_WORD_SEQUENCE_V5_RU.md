# Бумажное сминание по новому референсу и укатывание

`tipo_word_sequence_v5_real_paper_roll_1080p.mp4`: 1920 × 1080, 30 кадров/с, 149 кадров, 4,967 секунды, H.264 MP4, без звука.

Первые 92 исходных PNG-кадра одобренной анимации «УВИДЕЛ → КРИКНУЛ → ВЫИГРАЛ!» сохранены без изменения. Финал пересобран по `word_sequence_v5/input/reference.mov`: крупные жёсткие заломы, сложенные края, видимая светлая оборотная сторона и плотный бумажный комок. Вместо деформации сетки из предыдущей версии используются созданные по референсу фотореалистичные изображения бумажных поз. Это синтетические изображения, а не видеосъёмка настоящего листа.

После сминания комок перекатывается вниз. Используются восемь разных видов поверхности с последовательными поворотами вокруг горизонтальной оси; фрагменты печати и складки меняют положение. Путь центра связан с углом поворота формулой расстояния качения `s = rθ` (радиус 155 пикселей). Это последовательность ракурсов, а не плоский поворот одной картинки. Позы удерживаются по три кадра. Последние 15 кадров — пустое однотонное розовое поле `#FF006F`.

Исходники — `word_sequence_v5/assets/`. `build_animation.py` собирает анимацию, выделяя восемь отдельных видов из атласа без обрезания силуэтов. Требования: Python, Pillow, NumPy, SciPy; для MP4 — FFmpeg. Исходная последовательность версии 3 при необходимости восстанавливается автоматически её скриптом.

```bash
python word_sequence_v5/build_animation.py
ffmpeg -framerate 30 -i word_sequence_v5/frames/frame_%04d.png -an -vf 'scale=in_range=full:out_range=tv:out_color_matrix=bt709,format=yuv420p' -c:v libx264 -preset slow -crf 16 -color_range tv -colorspace bt709 -color_trc bt709 -color_primaries bt709 -movflags +faststart tipo_word_sequence_v5_real_paper_roll_1080p.mp4
```

Параметры кадров, поз и контрольные суммы записаны в `animation_manifest.json`. Проверки исходной анимации, разных ракурсов комка, траектории и пустого финала находятся в `video_validation.json`.
