# ТИПО — коробка №2: зацикленное вращение v1

`tipo_box2_turntable_v1.mp4` — готовый ролик 1080 × 1080, 30 кадров/с,
8 секунд. Коробка стоит на матовом чёрном столе и делает полный оборот
вокруг вертикальной оси, проходящей через центр основания.
Камера неподвижна, расположена прямо перед коробкой на высоте её центра.
Фон и стол чёрные; надписей поверх видео и звуковой дорожки нет.

## Файл Blender

Откройте `tipo_box2_turntable_v1.blend` в Blender 4.3 или новее.
Активная сцена — `TIPO_Box2_Turntable_v1`, диапазон кадров — 1–240.
Все текстуры упакованы внутрь файла. Нажмите пробел для просмотра анимации
на таймлайне; итоговый MP4 воспроизводится с фиксированной частотой 30 кадров/с.

Вращением управляет один объект Empty «Ось вращения». Все семь панелей
коробки и 61 карта вращаются вместе. Их форма, UV, материалы и положение
относительно друг друга сохранены из утверждённой коробки №2 v4.
Исходные утверждённые файлы коробок не перезаписывались.

Кадр 1 соответствует 0°, кадр 240 — 360°. Интерполяция вращения линейная:
ускорения, отъезда камеры, появления и исчезновения объекта нет.

## Замыкание видео

В готовом MP4 первый и последний кадры совпадают по всем декодированным
RGB-пикселям. Для устранения различий растеризации замыкающий PNG сохранён
из первого кадра той же позы. Кодирование H.264 выполняется с постоянным
квантизатором и независимыми кадрами; совпадение проверяется после декодирования
готового MP4, а не только на исходных PNG.

Подробные результаты проверки записаны в `tipo_box2_turntable_v1_validation.json`.
Проверяются длительность, частота и количество кадров, совпадение крайних кадров,
чёрный фон, неизменность исходников и геометрия анимационной сцены.

## Код настройки

`tipo_box2_turntable_setup_v1.py` создаёт отдельную анимационную сцену.
Перед запуском откройте утверждённый `tipo_box_61_cards_v4.blend` либо положите
его рядом со скриптом. Затем используйте **Scripting → Open → Run Script**.
Результат сохранится отдельным `.blend` в `Downloads/TIPO_ANIMATION`.
При повторном запуске существующий файл сцены не перезаписывается.

В начале кода доступны длительность, FPS, размер кадра и число сэмплов Eevee.
Для повторного рендера видео в Blender выберите **Render → Render Animation**.
Выходной файл указан в Output Properties. Для проверки пиксельного равенства
крайних кадров после нового кодирования сравните декодированные кадры:
контрольная сумма готового исходного ролика относится именно к поставленному MP4.
