# Россыпь карт — версия 3

`tipo_card_scatter_v3_stopmotion_1080p.mp4`: 1920 × 1080, 30 кадров/с, 90 кадров, 3 секунды, H.264 MP4, без звука.

Сохранено начало с пустым жёлтым столом и появлением руки снизу. В финале 40 карт. Все карты рисуются с одинаковой стороной 220 пикселей до поворота, включая карту в руке: теперь она тоже использует исходное изображение карты отдельным слоем под пальцами. Масштаб карт не меняется во время полёта; различается только поворот.

Карты выходят семью группами. Каждая проходит несколько отдельных покадровых поз: движение от центра наружу по слегка искривлённой траектории, поворот, небольшой выход за конечное положение и остановка. Это видимое перемещение по столу, а не смена неподвижных карт. Позы удерживаются по три кадра. В финальной композиции оставлены просветы жёлтого стола.

Скрипт `card_scatter_v3/build_animation.py` использует исходники из `card_scatter_v1/artwork/` и изображение руки без карты из `card_scatter_v1/assets/`. Для запуска нужны Python, NumPy и Pillow. `animation_manifest.json` содержит позиции каждой карты по позам и контрольные суммы исходников. `video_validation.json` содержит проверки размеров, траекторий, пустого начала, количества карт и декодирования готового MP4.
