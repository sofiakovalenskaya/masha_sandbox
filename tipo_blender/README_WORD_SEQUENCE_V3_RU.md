# Покадровая анимация слов — версия 3

Файл: `tipo_word_sequence_v3_stopmotion_1080p.mp4`.

Каракули стали толще, с весом штриха примерно как у букв. В читаемых словах контуры каждой буквы слегка меняются между отдельными рисунками: изменяется сама граница штриха, а не только положение буквы. Исходная печатная фактура и цвета сохранены.

Последовательность по предоставленным изображениям: **УВИДЕЛ → КРИКНУЛ → ВЫИГРАЛ!**. Длительность и ритм версии 2 сохранены: 92 кадра, 30 кадров/с, 3,067 секунды, 1920 × 1080, MP4 H.264, без звука. 28 отдельных рисунков удерживаются по 3–4 кадра без временной интерполяции.

Исходные изображения, слои и скрипт находятся в `word_sequence_v3/`. Для воспроизведения нужны Python, NumPy, SciPy и Pillow. Запуск `python word_sequence_v3/build_stopmotion.py` создаёт PNG-кадры и `animation_manifest.json`. `artwork_validation.json` содержит проверки сохранности исходников, удержания рисунков и фактического изменения контуров; `video_validation.json` — проверку финального видео.
