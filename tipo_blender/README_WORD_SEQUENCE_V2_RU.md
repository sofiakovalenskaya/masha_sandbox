# ТИПО — покадровая версия «Увидел / Крикнул / Выиграл!»

`tipo_word_sequence_v2_stopmotion_1080p.mp4`: MP4/H.264, 1920×1080, 30 кадров/с, 92 кадра / 3.066667 секунды, без звука.

Вторая версия использует отдельные удерживаемые рисунки: каракули → промежуточные очертания → выросшие буквы → короткие читаемые позы. Перед следующей надписью буквы снова сворачиваются в штрихи. Последняя надпись остаётся читаемой в конце.

Всего 28 рисунков. Каждый удерживается 3 или 4 видеокадра; между рисунками нет плавного интерполирования, волнового искажения, optical flow или растворения. Небольшие независимые смещения и повороты букв добавляют ручное подёргивание. Общая длительность на 15% больше исходного референса.

Читаемые позы собраны из букв исходных пользовательских PNG с их собственной фактурой. Промежуточные формы строятся между каракулями и силуэтами отдельных букв. Надписи идут в порядке «УВИДЕЛ → КРИКНУЛ → ВЫИГРАЛ!». Название последнего изображения сохранено из архива.

В `word_sequence_v2` находятся исходные PNG, выделенные слои, скрипт `build_stopmotion.py`, параметры рисунков и результаты проверки. Скрипт требует Python, NumPy, SciPy и Pillow; создаёт рисунки и кадры в папках `stopmotion_poses` и `stopmotion_frames`. Для кодирования MP4 используется FFmpeg.
