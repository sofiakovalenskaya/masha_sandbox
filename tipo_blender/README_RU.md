# ТИПО — исправленная пустая коробка из SVG

Текущая версия: коробка **67 × 67 × 27 мм**, с рисунком на лицевой стороне,
фигурным сквозным окном и полукруглой выемкой. **Карт внутри нет.**
Основание — полученный оригинал `коробка без лого.svg`.

## Самый простой способ

Откройте готовый файл `tipo_empty_svg.blend` в Blender 4.3 или новее.
Активная сцена — `TIPO_Empty_SVG`. Все текстуры упакованы внутрь.
Для повторного рендера нажмите F12. Файл `tipo_empty_svg.png` — выполненный
рендер именно с авторской графикой из обновлённого SVG.

## Запуск кода

1. Скачайте `tipo_box.py` целиком.
2. В Blender 4.x откройте **Scripting → Text Editor → Open** и выберите этот файл.
   Можно вместо этого вставить весь текст файла в новый текстовый блок.
3. Нажмите **Run Script** и дождитесь окончания рендера.
4. Файл `.blend` и изображение PNG сохраняются в `Downloads/TIPO_3D`.
   Результат рендера доступен через **Render → View Render**.

PNG, SVG и интернет для запуска не требуются: текстуры и векторные контуры
уже встроены в код. Дополнительные Python-библиотеки устанавливать не нужно.
Скрипт создаёт отдельную сцену, сохраняя существующие. Время рендера зависит
от компьютера; используется Cycles на CPU. В начале скрипта доступны
`RENDER_NOW`, `RENDER_SIZE`, `SAMPLES`, `OUTPUT_DIR` и толщина картона.

## Что исправлено

- Лицевая сторона получает отдельную текстуру из обновлённого SVG: жёлтые
  цветы, розовые завитки, зелёная графика и синие точки вокруг окна.
- Для печати задана явная UV-развёртка и привязка UV к текстурному узлу.
  При сборке проверяется, что рисунок действительно назначен лицевой поверхности.
- Панели вырезаны по координатам исходного SVG 2249 × 1609, без прежней
  привязки к уменьшенному изображению из чата.
- Фигурное окно и верхняя выемка построены по векторному контуру исходника.
  Допуск аппроксимации кривых — менее 0,01 мм; окно действительно сквозное.
- Карта, её текстура и прежняя зависимость от четырёх PNG удалены.
- Соседние грани используют соответствующие части развёртки: рисунок,
  пересекающий линии сгиба, переходит на боковины.
- Глянцевая ламинация, микрорельеф бумаги, нейтральный свет и камера сохранены.
  Текстуры хранятся в sRGB, используется Standard без дополнительного Look.
  Тени и блики физически меняют видимый цвет освещённой поверхности.

## Проверка и допущения

Скрипт выполнен и результат отрендерен в Blender 4.3.2 на настоящем SVG
пользователя. Проверены геометрия окна, назначение лицевой текстуры,
наличие всех четырёх цветов рисунка, упаковка изображений и отсутствие карт.

Толщина картона **0,35 мм** остаётся настраиваемым предположением.
Клеевых язычков нет; заправляемый клапан восстановлен по развёртке.
Это визуальная модель упаковки, не производственная проверка её замыкания.
Отдельный новый SVG логотипа пока не предоставлен; имеющаяся в исходнике
графика перенесена без замены.

Оригинальный SVG сохранён без изменений в `source/box_without_logo.svg`.
